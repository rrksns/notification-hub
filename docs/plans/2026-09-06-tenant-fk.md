# Tenant FK 참조 무결성 구현 계획

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** user-service의 사용자와 API 키가 유효한 테넌트를 참조하도록 Flyway FK를 추가한다.

**Architecture:** 현재 애플리케이션의 문자열 `tenantId` 계약은 유지하고, MySQL 스키마 migration에서 `users`와 `api_keys`의 `tenant_id`에 `tenants.id` 외래 키를 추가한다. 삭제 cascade는 정의하지 않아 테넌트 삭제 정책을 암묵적으로 바꾸지 않는다.

**Tech Stack:** Java, Spring Boot, JPA, Flyway, MySQL, JUnit 5.
